Autograder System for Dart Courses

Project information

  • Category: Others
  • Project date: Dec 20, 2024
  • Project Implementation: Dicoding

Mikasa is an automated grading system developed to support Dart programming courses by evaluating students' submissions quickly and reliably.

This project was created in collaboration with Alida Shidqiya. I was responsible for developing the Dart test modules that automatically verify the correctness of student submissions and designing the submission flow and structure. Alida developed the calculation system that determines whether a student has successfully completed the assignment.

We were guided by our amazing mentors from the Dicoding Academy team — special thanks to Kak Ilham, Kak Aras, Kak Dimas, Kak Deden, and Kak Arif 🙌

We're proud to share that Mikasa has been implemented in production, helping improve the learning experience for Dart students at Dicoding.

This project was part of our contribution during the Dicoding Internship – MSIB Batch 7. It's been a meaningful journey, and I'm grateful to have made a real impact.
